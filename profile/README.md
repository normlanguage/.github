## Build with Norm

Norm is a statically typed, application-oriented programming language with familiar syntax and explicit semantics.

Start with the [language tour](https://normlanguage.github.io/Norm/learn/), explore [runnable applications](https://github.com/normlanguage/examples), or use [agent tools](https://normlanguage.github.io/Norm/tooling/agent) to inspect and verify your code.

- **Packages:** [registry](https://github.com/normlanguage/registry) · [package standards](https://github.com/normlanguage/package-standards)
